For a rapid prototyping class I had to create a game that included two themes they gave, and I ended up with the themes of cookies and clouds. I settled on creating a small game where the player flies around through clouds to collect data to level up. <br/> To keep the gameplay loop simple I went with a pick three system as an upgrade system, which I made fully modulair with a simple abstract function for each upgradable component to state which variables are upgradable. <br/>The clouds are procedurally generated and able to be carved away by the player.<br/>
For the enemy system I went a little overboard by creating a finite state machine that I ended up not using as I didn't have time for more then a simple enemy.
